# linked-in-analyst-Nov-26
linked in analyst Nov 26


This project was completed as part of my AI and data apprenticeship to develop my practical understanding of Python, GitHub Codespaces, Jupyter Notebooks and using APIs with AI models.

I used a provided Python notebook to build a LinkedIn Post Analyser, which takes a LinkedIn post as user input and sends it to an AI model for analysis.

I worked through the code step by step, learning how prompts, functions, user inputs and API calls work together. I found parts of this project quite tricky, particularly understanding the Python code, getting the API connection working, dealing with different package versions and working out where errors were coming from.

There were points where the code didn't work as expected and I had to troubleshoot error messages, amend the code, test it again and work through problems one step at a time. I used AI assistance to help me understand what individual lines of code were doing rather than simply replacing the code.

I also learned about secure API key handling and why API keys should not be stored directly within a notebook or committed to GitHub.

Although I found the technical side challenging, working through the problems helped me understand much more clearly how Python can communicate with an AI model through an API. It also gave me practical experience of using GitHub, Codespaces and Jupyter Notebooks and increased my confidence in troubleshooting code when something doesn't work first time.

Overall, this project has helped me move from simply using AI tools to beginning to understand how AI can be incorporated into a program, which was challenging but a valuable part of my learning.
